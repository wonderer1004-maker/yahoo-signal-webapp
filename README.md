# Yahoo Signal Web App
모바일용 QQQ/TQQQ/QLD 매매신호 대시보드입니다.

- QQQ SMA175 추세필터
- Wilder RSI14 매수강도
- VIX 40 이상 위험회피
- 100만원 기준 목표비중 표시
- Yahoo Finance 데이터 자동갱신
- GitHub Pages 자동배포

## 최초 실행
Actions > Update Yahoo Signal > Run workflow를 한 번 실행하세요.
Settings > Pages > Source가 GitHub Actions인지 확인하세요.

교육·연구용이며 투자수익을 보장하지 않습니다.
